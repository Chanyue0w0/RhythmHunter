場景：Assets/FightDemo/Scenes/Art2_FightScene.unity
設定：FightDemoController > FightBossGemFinale

流程
- 第 95 拍起：停止三軌輸入判定、取消剩餘音符與已排音效；勇者靠攏，生成滿能量場景寶石與 A 提示。
- A 使用原本 Fever 輸入綁定，任意時刻按下皆計數，不需對拍；按住不連續計數。
- 每次按下播放現有 BeatTapping 成功音效、BlueExplosion_UI 特效（場景版使用，同一來源、物件池），寶石彈跳並提高藍光。
- 第 104 拍必定生成光束。不按 A 也勝利，但光束亮度與透明度較弱，長度保持能觸及 Boss。
- 目前 FMOD：121 BPM，Boss_End 約為二階段 113.4214 拍；104 拍發射後約有 4.672 秒光束演出。
- 歌曲結束仍由原本 BossRhythmBattle 處決 Boss，傷害 99999；光束不另結算傷害、不提前殺 Boss。
- Boss 死亡後 1 拍內淡出光束、降低寶石藍光；沿用原本死亡動畫及勝利面板。

Prefab
- Assets/FightDemo/Prefabs/VFX/GemUltRay.prefab：由原場景 GemUltRay 保存。原場景示範物件保留但停用，避免戰鬥多一條常駐光束。
- Assets/FightDemo/Prefabs/VFX/FinaleFullGem.prefab：SpriteRenderer 場景寶石，使用 UI 同款五張滿能量圖片。
- 圖片動畫復用 SceneBeatSpriteAnimator，仍取自 FMOD 節拍。

Inspector
- Finale Enabled：整套終結演出開關。
- Start Beat / Fire Beat：95 / 104，皆相對 Normal_End。
- Gather Beats / Gather Fraction：靠攏時間 1 拍，向中央靠攏 35%。
- Gem Offset / Gem Height：以中央勇者 ActorRoot 為基準的世界位置偏移與寶石世界高度。
- Gem Loop Beats、Bounce Amount / Beats：滿能量動畫與按鍵彈跳。
- Prompt Sprite：正式 A 提示圖欄位；未設定時僅顯示 A。
- Full Charge Presses：32 次達視覺滿充能；之後仍計數並播放每次回饋，但亮度不無限增加。
- Gem Light Color / Light Intensity / Light Range：藍光顏色、起始與最大亮度、範圍；不產生額外陰影。
- Beam Offset / Rotation Offset：光束相對寶石位置偏移與方向微調；光束局部 +Z 對準 Boss。
- Weak Beam Opacity：零次輸入時透明度 0.16；保留原始光束幾何與觸及距離。
- Beam Fade Beats：死亡後淡出時間，預設 1 拍。
